1. Lý thuyết cơ bản

Trong lập trình, câu lệnh điều kiện giúp chương trình đưa ra các quyết định rẽ nhánh dựa trên logic đúng/sai (true hoặc false).

Cấu trúc IF - ELSE

if (điều_kiện) {
    // Chạy khi đúng
} else {
    // Chạy khi sai
}

Cấu trúc Bậc thang (Else If)

if (dk_1) {
    // ...
} else if (dk_2) {
    // ...
} else {
    // ...
}
